Projetos

Automação de Cadastros com VBA e SAP

Desenvolvimento de uma solução de automação utilizando Excel VBA para análise, validação e processamento de dados cadastrais antes da integração com o SAP.

Desenvolvi rotinas para validação de informações fiscais, endereços, padronização de preenchimentos e organização de dados, além da integração entre Excel VBA e SAP para automatizar o envio dos cadastros após as validações.

Tecnologias utilizadas: Excel, VBA e SAP.

Automação de Consultas Cadastrais com Python e Power Automate

Desenvolvimento de uma solução para consulta e processamento automatizado de dados cadastrais de empresas por meio da API ReceitaWS.

Desenvolvi um programa em Python capaz de realizar consultas em lote a partir de uma base de CNPJs, processar os retornos em JSON e organizar automaticamente as informações em uma nova tabela estruturada, incluindo dados cadastrais, fiscais, situação do CNPJ, Inscrição Estadual e enquadramento tributário. A aplicação também conta com tratamento de dados, padronização de informações e interface gráfica para facilitar a utilização.

Posteriormente, a solução foi adaptada e reconstruída no Power Automate, visando sua implementação no ambiente corporativo.

Tecnologias utilizadas: Python, API REST (ReceitaWS), JSON, Excel e Power Automate.

Desenvolvimento de Portfólio Web

Desenvolvimento de um site pessoal para apresentação de perfil profissional, experiências, habilidades e projetos, com foco na construção de uma presença digital e organização de informações profissionais.

Desenvolvi a estrutura do site utilizando HTML5 e Bootstrap, implementando navegação entre seções, apresentação de conteúdo em cartões, layout responsivo e uma seção de contato para facilitar a comunicação. Também foram aplicados recursos de JavaScript para adicionar funcionalidades e interatividade à página.

Tecnologias utilizadas: HTML5, CSS, Bootstrap e JavaScript.
